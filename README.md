# $\color{#00BFFF}{\textsf{Booking Slice}}$

</div>

**Booking Slice** è un software ideale per la gestione di prenotazioni. L'obiettivo è quello di rendere più moderne le prenotazioni di tavoli in sala di una pizzeria e permettere anche di ordinare pizze da asporto. Tramite misure studiate ad-hoc, rende user-friendly l'uso del software sia lato clienti che lato personale pizzeria.
